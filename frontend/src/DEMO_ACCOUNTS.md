# 🎓 معلومات الحسابات التجريبية

## حسابات مجهزة للتجربة

### 👨‍🏫 حساب المعلم

```
البريد الإلكتروني: teacher@test.com
كلمة المرور: 123456
كود التفعيل: TEACH2024
كود الصف: ABC123
```

### 🎒 حساب الطالب

```
البريد الإلكتروني: student@test.com
كلمة المرور: 123456
كود التفعيل: STUDY2024
كود الانضمام للصف: ABC123
```

### أكواد الطالب:

- `STD123`
- `STD456`

- `STUDY2024`

---

## خطوات التجربة السريعة

### تسجيل دخول كمعلم:

1. افتح التطبيق
2. اختر "أنا معلم"
3. سجل دخول بالبريد `teacher@test.com` والباسورد `123456`
4. ستجد صف جاهز بكود `ABC123`
5. يمكنك نسخ الكود ومشاركته مع الطلاب

### تسجيل دخول كطالب:

1. افتح التطبيق في نافذة أخرى (أو سجل خروج)
2. اختر "أنا طالب"
3. سجل دخول بالبريد `student@test.com` والباسورد `123456`
4. اضغط على زر "صفي" في الأعلى
5. أدخل كود الصف `ABC123`
6. اضغط "انضم للصف"
